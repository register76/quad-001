# RadioMaster Boxer Backup

- Radio: RadioMaster Boxer
- EdgeTX: 2.x.x
- Protocol: CRSF (ExpressLRS)
- ELRS TX FW: x.y.z
- ELRS RX FW: x.y.z
- Typical Packet Rate: 250 Hz
- Model Match: (on/off)

## Contents
- `MODELS/` — model configs
- `RADIO/` — global radio settings
- `backups/boxer-backup.otx` — full EdgeTX Companion backup (optional)

## Restore
1. Copy `MODELS/` and `RADIO/` to SD card root, or
2. Use Companion → open `.otx` → Write to Radio.

⚠️ Binding phrase and Wi-Fi creds are not included for security.
