# Custom Quadcopter Project

This is an endurance-optimized 450 mm quadcopter powered by a CubePilot flight controller and running ArduPilot firmware.

## Goals
- Max flight time
- Modular design
- Open-frame for FPV and sensor expansion

## Key Components
- CubePilot flight controller (Cube Red → migrating to Matek F405-HDTE for first build)
- 4-in-1 HGLRC SPECTER 60A ESC
- 3112 900KV brushless motors
- DJI 1045 / 1147 carbon props
- 4S LiPo battery (3S & 6S also tested)
